# 分阶段详细清单与官方来源

核对日期：2026-10-17。费用/时效以各官方页面最新公示为准，标注 ⚠️ 的需现场核实。

## 阶段 0 — 主体与资质
- [ ] 确定统一主体（企业营业执照）
- [ ] 境内云账号企业实名（阿里云 / 腾讯云等）
- [ ] 主体一致性核对：域名实名 = ICP备案 = 公安备案 = 商户 = 小程序 = 短信 = 软著/商店开发者

## 阶段 1 — 域名与备案
- [ ] 域名实名（注册商，企业实名）
- [ ] ICP 备案（通过云服务商接入提交）— 工信部管理，⚠️ 免费
  - 来源：云厂商备案控制台（阿里云备案 / 腾讯云备案）
- [ ] 公安备案（全国互联网安全管理服务平台）
  - 来源：https://www.beian.gov.cn
- [ ] 页脚含 ICP 备案号 + 公安备案号可点击链接

## 阶段 2 — 服务器与网络
- [ ] 境内服务器 / CDN
- [ ] 移除境外依赖：Google Fonts、境外统计/SDK
- [ ] 字体本地化或换境内源
- [ ] 扫描硬编码境外域名

## 阶段 3 — 隐私与数据合规（个保法）
- [ ] 起草《隐私政策》《用户协议》
- [ ] 覆盖：收集清单、目的、第三方共享、权限说明
- [ ] 扫描代码个人信息收集行为（定位/相册/通讯录/相机），与政策一致
- [ ] 工信部 App 隐私合规治理要求自查

## 阶段 4 — 支付接入
- [ ] 微信支付商户号（企业资质 + 对公账户）
  - 来源：https://pay.weixin.qq.com
- [ ] 支付宝商户（开放平台）
  - 来源：https://open.alipay.com
- [ ] 回调验签、退款、账单集成代码

## 阶段 5 — 应用商店上架
- [ ] 软著申请（中国版权保护中心）或著作权声明
- [ ] 包体、截图、应用介绍、隐私政策链接
- [ ] 各商店分别提交：应用宝 / 华为 / 小米 / OPPO / vivo / App Store 中国区

## 阶段 6 — 短信服务
- [ ] 短信签名（与企业名一致）
- [ ] 模板报备（实名）

## 阶段 7 — 生成式 AI 备案（若含 AI）
- [ ] 履行算法备案 / 大模型备案 / 安全评估（网信办）
  - 依据：《生成式人工智能服务管理暂行办法》
- [ ] AI 生成内容标识（水印/声明）

## 阶段 8 — 上线前体检
- [ ] 运行 `scripts/compliance-check.py <url>`
- [ ] FAIL 项回到对应阶段修复，复测通过

## 依赖顺序（务必遵守）
主体一致 → 域名实名 → ICP备案 → 公安备案 → 服务器/网络 → 隐私政策 → 支付/短信/商店 → AI备案 → 体检。
